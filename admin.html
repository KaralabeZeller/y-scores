1. Connection and recovery

Use Ethernet or Wi-Fi prepared during installation. The optional recovery helper uses a separate protected setup network when saved networks are unavailable.

Changing Wi-Fi disconnects this page. Join the new network and reopen the board's local address, then confirm within 75 seconds. Otherwise the previous network is restored.

2. Name this device

Device ID (advanced)

Saving locks this ID permanently. Later you can rename the device. Duplicate names are allowed.

3. Optional Y-Sports account

Generate a temporary pairing PIN here, then enter it in My devices in Y-Sports management. The first signed-in account redeeming the PIN owns this device. Your local admin PIN stays on the Pi.

Match, court and schedule assignments are managed in Y-Sports. Local Manual, Logo and Blank selections take priority until you return to platform control.

Recover a revoked credential

In Y-Sports, an administrator opens Management → All devices → this device and generates a recovery code. Enter that twelve-digit code here. Recovery keeps this device ID and local settings, replaces its revoked secret and clears ownership. Then generate a pairing PIN to link an account again.

Software updates

Updates are requested in Y-Sports. Defer activation here during a local event.
