# Upcoming schedule display

The display shows only the next three unfinished fixtures in chronological order,
without rotating through later pages. The header contains UP NEXT, the first
fixture's date in the configured display timezone, and the court. Mixed-court
assignments show MULTI COURT. Times use digital badges; the next fixture is amber.
Each fixture shows its teams and categoryName from the authorized schedule feed.
Older servers without category metadata show CATEGORY TBD. Long labels are
bounded to the native 192x64 display; no device settings or pairing state change.
